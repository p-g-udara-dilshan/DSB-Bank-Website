# DSB Bank – Dolamawatha Sanasa Information Website

**A WordPress-based banking information website presenting institutional content and structured financial information.**

**Project type:** Client / Collaborative Web Development Project  
**Period:** 2025  
**Repository:** [DSB-Bank-Website](https://github.com/p-g-udara-dilshan/DSB-Bank-Website)  
**Availability:** Portfolio documentation; active public deployment is not claimed unless verified separately.

---

> 🏦 **Project overview**  
> DSB Bank / Dolamawatha Sanasa is an informational website for a local financial institution. The website focuses on communicating banking-related information, presenting deposit and service details clearly, and improving access to institutional content through a responsive WordPress interface.

## ✨ Website Features

- **Institutional homepage:** a prominent introduction and bank-focused navigation.
- **Information architecture:** structured sections for deposits and other service information.
- **Banking data presentation:** HTML tables for clearer display of financial product details where applicable.
- **Responsive design:** layouts adjusted for different screen sizes.
- **Readable styling:** custom CSS work on text presentation, contrast, spacing, and table layout.
- **Content management:** WordPress-based page and content organization.

## 🧰 Local Setup / Restoration

This is a **WordPress-based project**, not a standalone HTML/React application. The required installation steps depend on what files are actually present in this repository.

To recreate the original website **only if you have an authorized and complete site export**:

1. Prepare a local WordPress environment (such as Local, XAMPP, or an appropriate hosting account).
2. Install WordPress and provision a MySQL/MariaDB database.
3. Restore the original theme, child theme, plugins, media uploads, and database **if those backups are available**.
4. Review site URLs, WordPress permalinks, media references, navigation, and form configuration.
5. Reconfigure integrations and test the restored site on desktop and mobile.

**Important:** Screenshots, a theme folder, or a collection of page assets alone are **not** sufficient to restore a fully working WordPress installation. Do not publish database credentials, admin accounts, API keys, or private client information.

## 🔐 Scope, Safety & Status
